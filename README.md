# Personal Expense Behavior Analyzer

Everything for your project, in one folder.

## Files

| File | What it is |
|---|---|
| `expense_ledger.html` | The live web app. Double-click to open in any browser — upload a Paytm PDF or CSV, get an instant dashboard. Runs entirely offline, no install needed. |
| `analyze.py` | The Python/ML version — trains a Naive Bayes categorizer, predicts next month's spend, and runs Isolation Forest anomaly detection. Run with `python3 analyze.py`. |
| `transactions.csv` | Your real transaction data (16 Aug – 15 Sep 2026), already cleaned and ready to feed into either tool above. |
| `category_summary.csv` | Output: total spend per category. |
| `anomalies.csv` | Output: the transactions the model flagged as unusual. |
| `category_chart.png` / `daily_trend_chart.png` | Charts generated by `analyze.py`. |
| `Expense_Analyzer_Design.pdf` | The full project write-up — architecture diagram, module breakdown, tech stack, dashboard mockup, build timeline. Good for submission or viva. |

## To run the Python script

```
pip3 install pandas numpy scikit-learn matplotlib
python3 analyze.py
```

## To run the web app

Just double-click `expense_ledger.html` — it opens in your default browser.
